# 🎀 Girl Math - Scientific Calculator
A cute, pastel-themed scientific calculator built using HTML, CSS and JavaScript.

## *Live Demo*
✨ https://llamachan.github.io/Girl-Math/ ✨
## Features

- Basic arithmetic
- Scientific calculations
- Keyboard shortcuts
- Responsive layout
- Modern pastel UI

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

Clone the repository:

```bash
[git clone <repository-url>](https://github.com/Llamachan/Girl-Math)
```

Open `index.html` in your browser.
